# Security and Authorization

Use this project only for authorized security assessment and education.

- Test only systems for which you have explicit authorization.
- Keep vulnerable training applications isolated or bound to localhost.
- Never test third-party production systems without written permission.
- Do not commit real credentials, API keys, private keys, personal data, or production logs.
- Use synthetic data and sanitize screenshots.
- Record target, authorization, timestamp, test case, result, and evidence for real assessments.

The report is a controlled-lab capstone and must not be represented as a real production assessment without genuine authorized evidence.

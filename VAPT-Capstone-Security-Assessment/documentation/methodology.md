# VAPT Methodology

1. Pre-engagement: define authorization, scope, exclusions, timing, contacts, and evidence rules.
2. Reconnaissance: identify approved assets and application interfaces using non-destructive methods.
3. Vulnerability identification: review authentication, authorization, input validation, configuration, headers, logging, and dependencies.
4. Validation: safely validate suspected weaknesses in the isolated lab.
5. Risk analysis: assign CVSS 3.1 and OWASP mappings; consider business context separately.
6. Reporting: document evidence, impact, root cause, remediation, owner, and timeline.
7. Retesting: reproduce the original test, confirm the fix, and check regression/bypass paths.

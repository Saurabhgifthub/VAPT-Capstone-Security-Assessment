# Executive Summary

This capstone presents a controlled VAPT assessment framework for executive review. It focuses on common application and configuration weaknesses affecting confidentiality, integrity, and availability.

The priority areas are injection, access control, authentication, security configuration, and sensitive information exposure. CVSS 3.1 communicates technical severity while OWASP categories provide application-security taxonomy.

The remediation plan separates urgent fixes from short-term hardening and includes retesting so that remediation is verified rather than assumed.
